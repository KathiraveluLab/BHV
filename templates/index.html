About BHV
Purpose

BHV complements traditional Electronic Health Records (EHRs) by providing a secure platform for storing patient-provided visual content and narratives that document recovery journeys.

Key Features
  • Secure image upload and storage
  • Narrative text association
  • Role-based access control
  • Comprehensive audit trails
  • Healthcare compliance (HIPAA)
User Roles
Patient Upload and manage personal images and narratives
Social Worker View patient content and add clinical notes
Admin Full system access and user management
Security

All data is encrypted at rest and in transit. Access is logged for compliance and security monitoring.
